# Лабораторная работа №1

Репозиторий создан для изучения базовых коман Git в рамках дисциплины «Программное обеспечение центров обработки данных».

## Цель

Освоить создание локального репозитория, индексацию изменений, создание коммитов и публикацию истории на GitHub.

## Совместная работа

Ветка `feature/lab2-collaboration` используется для отработки GitHub Flow и слияния изменений через pull request.
